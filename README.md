# 风聆Studio（Fengling Studio）

**官网：[gnmusic.cn](https://gnmusic.cn/)**

风聆Studio 是给 Suno 用户用的电脑端上传与歌词工具，有 Mac 版和 Windows 版。这个仓库放的是风聆Studio 的公开说明文档：安装、激活、常见问题的索引。软件本身不在这里开源，安装包请只从官网下载。

> 风聆Studio 是独立的第三方工具，与 Suno 官方没有隶属或授权关系。请只处理你有权使用的内容。

## 安装（Mac）

1. **查芯片**：苹果菜单 →「关于本机」，看「芯片」或「处理器」一行。显示 Apple M 系列选 Apple 芯片版，显示 Intel 选 Intel 芯片版。
2. **下载**：在 [官网下载页](https://gnmusic.cn/download/) 下载对应的 DMG，等文件完整下完再打开。
3. **安装**：双击 DMG 里的「风聆Studio」，点「自动安装并打开风聆Studio」。不需要把图标拖进「应用程序」。要求 macOS 11 及以上。
4. **激活**：首次打开输入卡密，看到激活成功和有效期后再继续。
5. **连接 Suno**：按软件提示登录你自己的 Suno 账号。

完整步骤和截图见 [安装与使用指南](https://gnmusic.cn/guide/)，也可以看 [视频教程](https://gnmusic.cn/tutorial/)。
